# 🚀 Chintamani Vijay Ginde — Premium Interactive Portfolio

A modern, high-end, responsive, and animated personal portfolio website for **Chintamani Vijay Ginde** (B-Tech CSBS Student, Technical Co-Head @ CABSSA, and Technology & Business Enthusiast).

Built with **React**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, and **Lucide Icons**.

---

## 🌟 Key Features

- **Split Editorial Hero**: High-impact typography, portrait showcase frame, active status badges (`TECHNICAL CO-HEAD @ CABSSA` & `BEST VOLUNTEER`), and action CTAs.
- **Custom Magnetic Cursor**: Interactive lag-behind desktop cursor with `"VIEW"` hover states.
- **01 — Profile**: Editorial layout with interactive animated keywords (*Technology, Business, Finance, Automation, Event Management, Frontend Development*).
- **02 — Technical Skills**: Interactive ecosystem with a live capacity central hub and 8 tech nodes (*Website Management, Email Automation, WhatsApp Automation, Google Forms, Google Drive, Frontend Development, C, C++*).
- **03 — Business + Finance**: Visual metaphor pipeline (`IDEA → MANAGEMENT → OPERATION → GROWTH`) with horizontal scrolling domain cards.
- **08 — Featured Project (DhanSetu AI)**: Dedicated flagship project showcase for [DhanSetu AI](https://dhan-setu-ai-plan.lovable.app/) with live demo launch button.
- **04 — Experience & Leadership**: CABSSA Technical Co-Head current leadership role and TechNegotia volunteer experience featuring an interactive click-to-enlarge **Best Volunteer Award Lightbox Modal**.
- **Signature Hybrid Profile**: *"TECHNICAL ENOUGH TO BUILD. BUSINESS-MINDED ENOUGH TO UNDERSTAND WHY."* dual-column comparison with a sync beam.
- **05 — Strengths**: Interactive kinetic cards for Communication, Teamwork, Event Coordination, Leadership, Problem Solving, Quick Learning, and Business Mindset.
- **06 — Academic Showcase**: 3 distinct metric compartment boxes (**9.1 CGPA in B-Tech CSBS**, **95.86% in 10th**, and **67.5% in 12th**).
- **07 — Currently Learning**: 4-stage Frontend Development pipeline (`LEARNING → PRACTICING → BUILDING → IMPROVING`).
- **Contact & Footer**: Direct email & call actions with one-click copy handlers, and active links to **LinkedIn** and **GitHub**.

---

## 🛠️ Tech Stack & Dependencies

- **Framework**: React 18+ (Vite)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React & inline SVG brand icons

---

## ⚡ Local Setup & Commands

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build production bundle**:
   ```bash
   npm run build
   ```
